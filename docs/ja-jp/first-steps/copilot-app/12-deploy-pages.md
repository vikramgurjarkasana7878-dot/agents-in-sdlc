Space Quiz を GitHub Pages にデプロイして、誰でもアクセスできる場所に公開しましょう。Copilot はワークフローの準備とデプロイの案内を行えますが、変更をレビューし、サイトが公開されたことを確認するのはあなたの役割です。

このレッスンでは、次のことを行います。

- Copilot に GitHub Pages デプロイの設定を依頼します。
- ワークフローと pull request をレビューしてからマージします。
- デプロイを追跡し、公開されたサイトを確認します。

## シナリオ

Space Quiz はすでに GitHub リポジトリにありますが、まだ手軽に試せる方法がありません。単一ファイルのサイトを GitHub Pages で公開すれば、サーバーやランタイム依存関係を追加せずに、公開 URL から利用できるようになります。

## Copilot にデプロイを準備してもらう

> [!WARNING]
> pull request の作成によって、コードが commit および push されることがあります。プロンプトを送信する前に、承認設定と送信先リポジトリを確認してください。**すべて承認**に設定されている場合、個別の確認は表示されません。

`space-quiz` の Copilot app セッションで、次のプロンプトを送信します。

```plaintext
Prepare a GitHub Pages deployment for this repository. Create a GitHub Actions workflow that builds the website if needed and deploys it to GitHub Pages after changes reach the default branch. Add a README describing the app and how to run it locally if one does not already exist. Create a pull request with these changes and report its link and any required Pages settings or permissions. Do not merge, enable auto-merge, change Pages settings, or deploy. Stop and wait for my review.
```

## ワークフローと pull request をレビューする

1. README がまだない場合に限り追加されていることを確認します。
2. ワークフローのビルドとデプロイの手順、トリガー、権限を含めて pull request の変更をレビューします。
3. ワークフローが、マージ前の pull request ではなく既定のブランチからデプロイすることを確認します。
4. 修正が必要な場合は依頼し、更新された差分をレビューします。マージを承認する前に、必須の pull request チェックが成功するのを待ちます。

## マージとデプロイを承認する

> [!WARNING]
> 次のプロンプトは、レビュー済み pull request のマージ、リポジトリの Pages 設定の変更、サイトの公開をエージェントに許可します。レビューを完了し、リポジトリと pull request を確認した後にのみ送信してください。承認設定によっては、これらの操作に別途確認が求められないことがあります。

`<PR_NUMBER>` をレビューした pull request の番号に置き換えてから、別のプロンプトとして送信します。

```plaintext
I have reviewed pull request <PR_NUMBER> in this repository and authorize its merge and deployment. Enable GitHub Pages using GitHub Actions, merge that pull request only after required checks pass, and monitor the deployment until it succeeds. Report the final URL of the live website. If you lack permission to enable Pages or merge, tell me exactly what I need to approve or do; do not report success until the site is live.
```

## デプロイを確認する

1. GitHub Actions のデプロイ実行が成功するまで確認します。
2. 報告された URL を開き、Space Quiz が表示されることを確認します。

エージェントが Pages の有効化や pull request のマージを行えない場合は、案内された手順に従ってください。デプロイが成功し、公開サイトが読み込まれるまでは、作業完了とみなさないでください。
